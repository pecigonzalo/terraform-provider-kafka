```release-note:upgrade-note
resource/`kafka_topic`: Run `terraform plan` after you upgrade. Read the plan before you apply it. If you do not set `configuration`, the plan changes `configuration` to null. If you set some keys, the plan removes the other keys from state. When you change `configuration`, the provider now sets the keys that you manage and deletes the keys that you removed. It does not change any other setting. In v0.5.3, state held all broker settings. For this reason, the first change after the upgrade deletes every key that was in the old state and is not in your `configuration`. For a key at the broker default, this changes nothing. A setting that is not at the default and was in the old state returns to the broker default. To keep such a setting, add it to `configuration` before you apply. Settings that you or another tool set after the upgrade are not changed.
```
