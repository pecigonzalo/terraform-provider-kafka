```release-note:new-resource
`kafka_acl` manages one ACL entry. Kafka cannot change an ACL, so a change to any attribute replaces the entry. `host` must be `*` or one IP address. Kafka matches hosts exactly. It does not support network ranges (such as `10.0.0.0/8`), partial wildcards or host names, so an ACL with such a host never matches a client. The principal type `User` must have this exact case. Write `User:alice`, not `user:alice`. Plan gives an error for a value that is not valid. Create and delete wait until the broker shows the change. The wait lasts at most as long as the provider `timeout`. If it takes longer, the error tells you to run `terraform apply` again. To import, use the id `resource_type|resource_name|resource_pattern_type|principal|host|operation|permission_type`, for example `topic|orders|literal|User:alice|*|read|allow`. In a value, write `%` as `%25` and `|` as `%7C`. (#177, #184)
```
